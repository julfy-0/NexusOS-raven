# Wallpapers

Положи PNG-файлы сюда под именами `wall1.png` ... `wall5.png` и пересобери (`make -j2 iso` или `./build_pc.sh`).

- Нужен Pillow: `pip install pillow`. Без него (или без файла) слот получает градиент-заглушку.
- Картинка масштабируется с обрезкой по центру до 800x450 (16:9), на экране растягивается билинейно.
- `nexus_default.rgb565` — встроенные обои (слот 0).
- Выбор: Settings -> Personalize, или в терминале GUI: `wall 0..5`.
